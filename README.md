## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Apumukherjee819/Apumukherjee819.github.io.git
   cd Apumukherjee819.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Type Check & Build**:
   ```bash
   npx tsc --noEmit
   npm run build
   ```
